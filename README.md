# XOR Viewer - Chrome Extension

一個 Chrome 擴充功能，用於下載指定 URL 的檔案內容，進行 XOR 解碼後顯示結果。

## 功能

- **右鍵選單** — 對網頁上的連結右鍵，選擇「XOR 後顯示」，自動下載並解碼
- **手動輸入** — 點擊擴充功能圖示，貼上 URL，按下「顯示並 XOR」

## 安裝方式

1. 開啟 Chrome，前往 `chrome://extensions/`
2. 開啟右上角「開發人員模式」
3. 點擊「載入未封裝項目」
4. 選擇此專案資料夾

## 使用方式

### 右鍵選單

在任意網頁中，對連結按右鍵 → 選擇「XOR 後顯示」，即可在新分頁中查看解碼後的內容。

### Popup 輸入

1. 點擊工具列上的 XOR Viewer 圖示
2. 在輸入框中貼上目標 URL
3. 點擊「顯示並 XOR」

## 技術細節

- XOR Key: `168` (`0xA8`)
- 使用 Manifest V3
- 解碼結果以 `data:text/plain` 在新分頁中呈現
